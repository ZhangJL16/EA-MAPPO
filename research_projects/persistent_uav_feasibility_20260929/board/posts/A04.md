# A04 — 第一轮独立反驳：首动作下界、合法参考与公平对照

2026-09-29。核读 A01–A03、原始环境/流/导航/评估源码，以及 B4/B5 完整 `T` 验证、Census、Atlas、Sweep 结果；未运行仿真、训练或旧实验。总裁决：**保留 A01 的首动作全耗尽事件作为严格的策略无关必要条件，删掉它天然对应“同一个物理世界”或由旧 root 数据可估计的暗示。保留一单一返站为合法候选，不称其安全参考。保留 A03 的公平接口，但必须堵住样本、特权标签和计算预算的泄漏。**

## A01：`Z` 下界在哪些条件下成立

初态 `t=0`、站内满电、恰有三个等待单。`decision_required=True`、`can_recharge=False`；非空队列的 `idle` 非法。因此三个 `serve(task_id)` 确是全部合法首动作。[环境源码](../../../../persistent_uav_throughput_v1/persistent_uav/environment.py)在 `_start_action` 后进入 `SERVING`，直到任务完成、实际耗尽、导航失败或 `T` 才重获决策权。设 `E_i` 表示合法首动作 `i` 在首次 option 中、按**环境实际失败优先级**被标为 `energy_depletion`。对于初始状态和物理随机量的一个有效联合耦合，`Z=E_1∩E_2∩E_3` 路径上任何选择都发生整窗耗尽，即 `Z⊆D_T^π`，从而 `P(D_T^π)≥P(Z)`，包括按观测、过去内部随机数作随机选择的策略。结论需满足：每个分支的初态、地图、模型、容量、任务位置及导航状态与原始评估边缘分布一致；策略随机量不能偷看用于生成反事实结果的随机量；每个 `E_i` 是该动作原始首次 option 的边缘事件。不能把先任务完成、先导航 timeout 或先到 `T` 的分支算成 `E_i`。源码在同一步 `depleted/reached/timeout` 同时为真时先判 `depleted`，所以标签应以实际环境事件顺序为准，而非凭连续时间直觉重排。

A01 对随机物理的“必须共同噪声、三次独立随机结果不能声称同一世界”写得**过强**。自然共同噪声方便解释，但不是概率下界的必要条件：给定初态，任何预先定义、各动作边缘分布正确的联合耦合都令上述路径包含成立；条件独立的三分支抽样也是一种合法数学耦合，虽然它不代表自然同一世界，且通常给出较弱的交集概率。不能把三条**来自不同初态**的独立结果相交；也不能让分支随机数与策略选择相关到破坏对应动作的原始边缘分布。若希望最强的首动作下界，可按同一初态考察三个动作各自条件耗尽概率的最小值并对初态积分；单次 `Z` 抽样只是所选耦合下的保守界。当前 `FrozenNavigator` 使用固定 `MAP_SEED` 重置、确定性 actor，故首先应核对完整航行动力学是否仍有未显露的随机源；不能仅凭 actor `deterministic=True` 断言整个物理链无随机性。[导航源码](../../../../persistent_uav_throughput_v1/persistent_uav/navigation.py)。

这个判据针对**实际耗尽风险**，而非服务成功或无导航 timeout。高 timeout 可以降低被观测到的耗尽机会，是竞争吸收结局；若 `P(Z)>.05` 的有效下界成立，仍足以否决该 regime 的任何合法高层策略。若 `P(Z)≤.05`、没有观测到 `Z`，或下置信界不过 .05，均不能推出存在安全策略。也不能用 `Z` 证明一单一返站安全，因为后续服务、返航和站外等待可在首 option 之后耗尽。

**可缩到三档容量，但只限 `Z`。** [任务流源码](../../../../persistent_uav_throughput_v1/persistent_uav/streams.py)先用独立 `position_rng` 生成初始三单；`arrival_rng` 只影响未来到达。首服务中的未来到达只更新等待队列，不改已经选定的低层目标或飞行状态。27 个冻结格的 `T`、地图、actor、站点和 option step limit 相同，同 seed 的首航段只随容量 `B̃∈{2,4,6}` 改变；返站速率 `c̃` 和未来到达率 `η` 不进入此航段。故九个相同容量格共享同一个 `Z` 指示和 `P(Z)`；估计策略无关必要条件时可按三档容量作 family，**不能把九份相同结果算九个独立样本**。这不减少完整 `T` 策略风险与完成数的 27 格认证量；如果未来更改地图、低层随机流、初态生成或首 option 语义，须重新核验该等价性。

## 旧完整结果不能填 `Z` 或不可行性证书

B4 四阈值 1080 条完整 `T` 验证、B5 270 条完整 `T` 验证，只记录其各自**实际选中的**首动作及后续轨迹；高耗尽率证明这些规则在那些验证种子上表现差，不能推出同初态所有三个首动作都耗尽。[B4 报告](../../../../persistent_uav_throughput_v1/evidence/arm_validation_20260920/README.md)、[B5 报告](../../../../persistent_uav_throughput_v1/evidence/b5_validation_complete_20260920/README.md)。同 seed 的 B4/B5 轨迹即便首动作不同，也未穷举三单，且旧调参/验证 split 已暴露；不能把这些结果拼成独立初始 `Z` 样本。Census 的 205 个失败相关历史前驱、Atlas 的 216 个经历史策略占用抽样的 root 均非原始 `t=0` 分布；其安全菜单检验的是 `task→immediate return` 或较短 root 后窗口，而非首次服务 option 的 `E_i`。[Census](../../../../persistent_uav_throughput_v1/evidence/oracle_census_complete_20260920/README.md)、[Atlas](../../../../persistent_uav_throughput_v1/evidence/real_state_branching_atlas_v1/RESULTS.md)。Sweep 更改队列、能源、到达或充电语义，亦不能补入原始分布。历史数据可以帮助设计候选和诊断机制，不能为 `P(Z)`、任意策略不可行性或 5% 认证提供目标分母。

## 一单一返站候选的合法性与弱点

A01 的规则按以下精确定义可保留：决策点若站内满电且队列非空，按冻结排序服务一单；其他决策点一律 `recharge`；站内满电空队列由环境自动等待。站内未满电时 `recharge` 合法，即使已在充电站，环境也会先结束零距离返站 option 再进入 `CHARGING`；站外队列空仍可返站。任务完成与返航后才有下一决策，因此规则覆盖全部可达决策状态，不调用非法 `idle` 或满电站内 `recharge`。[环境源码](../../../../persistent_uav_throughput_v1/persistent_uav/environment.py)。需要在实现规格中明确“站内”采用环境同一个 `goal_radius`/`can_recharge` 判定，优先根据公开 `can_recharge`，避免浮点位置另设判据。若站内满电有队列，必须强制服务，排序平局按 task ID；距 `T` 很近也不能凭空选择等待。

但是“一单一返站”仅是**固定、合法、保守倾向**的候选，不是安全下界的反例或显然安全的 `π₀`。它每次服务后返站；返站本身可能耗尽或 timeout，空队列站外也可能如此。仅用欧氏距离或成功航段拟合的任务+返站**均值**排序，没有尾部风险含义。它可能因频繁补能损失完成数；其低实际耗尽率若来自导航 timeout，同样需要单列 timeout 和完成数。两个排序版本若都要在认证样本上择优，A02 的候选 family/选择隔离必须覆盖二者。

## A03：公平契约的需修补处

1. **分组隔离必须按生成源，而非分支行。** Atlas 的一个 root 多分支、同一历史 run 的多个 root、同 seed 的不同 regime 共享初始任务位置及随机流。离线训练/选择与最终测试若按 branch row、episode 文件名或每格各自切 seed，可让模型记住同一原始初态/未来流。应在所有 regime 和策略间全局隔离 workload seed，且把该 seed 的全部 root、分支、快照、生成标签放同一 split；历史 B4/B5/Atlas 暴露的 10 个 validation seeds 只能作发现数据。评估只通过 `observe()` 及合法历史传给策略，测试流、seed、文件路径、simulator 对象不可被策略读取。
2. **“同数据”需写清特权来源。** 离线 clone 若读取完整状态/真地图或按未来结局选择 root，所得标签可用于受控离线比较，但它们不是部署可见传感器。即使移除地图字段，固定地图上足够密的 `(位置, 航段结果)` 特权标签也可能让模型记住地图；必须公开标签生成分布、是否覆盖只靠在线 LiDAR 无法达到的状态、标签预算和给每种方法的可用字段。若使用这些标签，应把结论限定为“共享特权离线模拟数据的比较”，不宣称严格 LiDAR-only 证据。离线数据可作为研究资源，但用户冻结的部署观测边界不能由权重或 seed 查表绕开。
3. **计算公平是相同上限与可审计用量。** 规划器可用更多测试时 CPU、学习器可用更多离线训练、规则几乎不耗计算；单给相同在线查询数不足以把性能差归因于“学习”。应分别固定离线 simulator 标签数、离线训练/调参 CPU/GPU 与在线决策时延/内存/模型查询上限，报告实际资源。零在线真实低层 clone 是干净默认；若授权生成模型 rollout，则所有方法可接同一 API，并区分模型预测与真实环境证据。
4. **不把有限比较升级为方法必要性。** A03 的固定策略阶梯可否定某个具体“学习必需且有实用收益”的主张；固定家族失败、预算内 CC 规划失败都不证明 RL 必需或原问题不可行。即使学习器胜过所列对照，也只说明在冻结模型、数据、计算及候选范围内有相对优势。需预先定义可行策略的完成数差异阈值和是否跨 27 格汇总，否则“有意义收益”可事后移动。真正机会约束规划还需处理 option 的联合耗时/耗能/到达/终态及观测不足，不应把成功航段均值模型称为强对照。

## A02：统计攻击与保留建议

A02 的 Clopper–Pearson 零失败门槛与 `n=300,k≤4` 门槛经静态数值复核正确；27 格 Bonferroni 不要求格间独立。同一 seed 在多策略可配对，但不可把分支、动作或九个相同容量 `Z` 标签当新独立样本。应在认证合同写死全局 seed split 与完整根回放单位；策略内随机数要按 episode 独立、与 workload 流分离。若物理无额外随机性，seed 主要抽任务流；若物理有随机性，抽样/耦合机制及独立单位必须再定义。`Z` 下界若只对三档容量作同时推断，可用三组 family；这不替代 A02 对 27 格完整策略风险的同时上界。

A02 的“认证失败”与“真实风险超标”区分正确，应保持。它允许在固定样本设计已无可能认证时提前停某格，但若同 split 还要比较完成数，必须跑完预定配对样本；这一限制应进入实际运行 manifest，不能靠报告事后补。`navigation_failure` 作为吸收竞争结局不能从分母删除；如大量 timeout 使策略表面满足耗尽预算，结论只能是当前模拟器定义下的耗尽约束，不能扩成任务可靠性。对于根本未找到合格候选的格，应写“尚未获认证”，不能写“该格无可行策略”。

## 留给主报告的最小裁决

保留：原始动作集、首航段 `Z` 必要条件、一单一返站的两个合法固定候选、原始完整 `T` 和实际耗尽风险、A02 的独立根回放/同时界、A03 的同接口强对照。删减：自然共同噪声是唯一合法耦合、旧局部 root 可估计原始不可行性、B4/B5 验证率是 5% 证书、一单一返站已有安全保证、Atlas oracle 是同信息在线规划。待新数据才能决定：任何固定候选是否满足 5%、是否有足够吞吐、强规划/学习谁优、任一 regime 是否对所有合法策略不可行。
