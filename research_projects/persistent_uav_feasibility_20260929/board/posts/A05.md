# A05 — 第二轮独立复核：首动作下界与待运行脚本

日期：2026-09-29。静态核读 A01、A02、A04、`checks/run_initial_choice_lb.py`、`checks/collect_initial_choice_lb.py`，并回查冻结环境、导航、任务流和 regime 构造；**没有运行仿真、训练或新的实验**。裁决：首动作下界是有效的**策略无关必要条件**，runner 的首 option 分类与原环境失败优先级相符；但在用于正式排除 27 格策略可行性之前，应修补 manifest 并发初始化、代表 regime 等价的机器可核查证据，以及 collector 的行完整性验证。当前脚本还不是已产生证书的结果。

## 数学量词与统计结论

初始满电站内有三单，`can_recharge=False`，非空队列不能 `idle`，所以任何合法高层策略的首动作只能是三个 `serve(i)` 之一（[`environment.py` 53–73, 107–131](../../../../persistent_uav_throughput_v1/persistent_uav/environment.py)）。给定一个具有正确条件边缘分布的反事实耦合，令 `E_i` 为 `serve(i)` 首个非抢占 option 按环境规则先发生 actual energy depletion，`Z=E_0∩E_1∩E_2`。若策略仅依赖合法观测及其独立私有随机数，则逐路径 `Z⊆D_T^π`，故**同一** `q_B=P(Z)` 对该容量组的**每个**合法策略都有 `P(D_T^π)≥q_B`。这里的量词是 `∀π, p_π≥q_B`，不是每条策略分别估一个下界，也不是只针对已试规则。即使首次 option 完成后还有任务流，该包含关系仍成立；`Z` 的充分事件已在第一次再决策前发生。

A04 指出自然共同噪声并非唯一可用耦合，这一修正正确：若物理随机，每个分支必须有原动作的正确条件边缘，策略的私有随机数不得偷看反事实抽样。按初态独立抽三个分支也可给**保守**交集下界，但不能说是自然同一物理轨迹。当前 runner 每条分支以同一 `MAP_SEED` 新建冻结导航器、同一三个初始任务位置和完整 workload；低层 actor 明确 `deterministic=True`（[`navigation.py` 84–105, 163–196](../../../../persistent_uav_throughput_v1/persistent_uav/navigation.py)）。这与冻结模拟器当前首航段一致；如未来物理引入额外噪声，应重审耦合。导航 timeout、首单成功或到 `T` 截断都令该分支 `E_i=0`；不能把它们算作耗尽，也不能从完整 `T` 失败样本拼凑 `Z`。

对每个容量组固定 `n=100` 个**不同初始 seed**，`K=ΣZ` 是二项计数（在模拟器独立 seed 抽样约定下）。三个不同容量的逐组声明用 `α=.05/3`，单侧精确上尾 `P_{q=.05}(Bin(100,.05)≥K)`；`K≥11` 才拒绝该组的 `q_B≤.05`。若三组都过线，才可映射到 27 格的「所有合法高层策略均不满足 5%」；若仅一组过线，只能排除该组对应的九格。任何不过线、零 `Z` 或上界不足都**不证明存在**安全策略。A02 的整窗固定策略风险上界、吞吐比较仍需各自独立完整 `T` 数据；本短检验不替代。若把这项检验与其他认证合并为同一 95% 结论，须事先重新分配总错误预算；`0.05/3` 只管本检验的三个声明。

## 三档容量等价与 runner 首 option

冻结 27 格确实由容量、充电倍数、到达负载的全因子生成（[`calibration.py` 37–45](../../../../persistent_uav_throughput_v1/persistent_uav/calibration.py)）；同容量九格共享 cutoff、初始任务数、地图、导航 option limit。`workload` 用独立位置流先生成三个初始位置，未来到达率仅改变后续到达时间/数量（[`streams.py` 30–42](../../../../persistent_uav_throughput_v1/persistent_uav/streams.py)）。首服务期间到达只改等待队列，不能抢占或改变低层目标（[`environment.py` 84–104, 193–204](../../../../persistent_uav_throughput_v1/persistent_uav/environment.py)）。充电率也尚未被调用。因此代表格的 `Z` 可对应九格；九个副本绝不能算九倍样本量，且**整窗**风险不随之缩成三格。

runner 用 `Config(**group["config"])`、同一 `tasks` 克隆三条首任务，在第一个非耗尽分支后停止；`first_branch` 在 `env.done` 或 `mode != SERVING` 才退出，按 `env.failure` 优先分类，因此保留了环境中 depletion 优先于 reached/timeout 的实际判定（[`run_initial_choice_lb.py` 104–157](../../checks/run_initial_choice_lb.py)，[`environment.py` 193–203](../../../../persistent_uav_throughput_v1/persistent_uav/environment.py)）。它没有续跑返站/充电或完整 `T`，也没有把导航 timeout 当耗尽。`FrozenNavigator` 和旧环境源码在此次审查时无 Git 改动；新脚本只在本独立项目中。

**需修补 1：等价性目前只靠人读证明。** [`run_initial_choice_lb.py` 57–68](../../checks/run_initial_choice_lb.py)只断言三种容量各九格，就选最小 ID 的 `config`；没有验证每组九格的 `cutoff`、`initial_tasks`、`queue_capacity`、`option_step_limit`、地图/导航版本以及同 seed 的初始三任务位置相同，也没有存同组首航段等价审计。当前冻结文件和源码支持缩约，但若以后文件变更而仍恰好「3×9」，脚本会静默把不等价格合并。最小修复：构造 manifest 时逐组断言所有影响首 option 的配置/初始位置生成契约相同，记录这些字段和 frozen hash。若静态等价条件不能完全证明，才提出一个有明确停止规则的同组标签一致性小型 smoke，按父目录 AGENTS 的额外检查审批要求另行获批；该 smoke 不计入 `K`。若发现不一致则退回 27 格设计，不能继续按三组发表。

## 恢复、manifest 与 collector 的具体缺口

**需修补 2：manifest 不是原子创建。** [`run_initial_choice_lb.py` 86–101](../../checks/run_initial_choice_lb.py)在所有 worker 都可能调用的 `ensure_manifest` 中使用 `open("x")` 后直接逐步 `json.dump`。第二个 worker 见到已创建但尚未写完的文件会 `json.loads` 半份 JSON 而失败；首 worker 被中断可留下一份无法恢复的截断 manifest。行和 status 使用临时文件加 `os.replace`，这一点更好（39–49、188–208）。最小修复：在启动 worker 前单进程 `--init-only` 以临时文件、`fsync`、原子发布完成 manifest，再让 worker 只读核对；或用独占锁覆盖创建/读取全过程。若要求断电耐久，再 `fsync` 目录。输出目录已有无关文件时也应拒绝新建 manifest 或显式走恢复模式。

**需修补 3：collector 仅核对部分字段。** [`collect_initial_choice_lb.py` 42–67](../../checks/collect_initial_choice_lb.py)确实检查预期 `(capacity,seed)` 唯一、合同 SHA、regime IDs、分支顺序、早停、跳过 ID 与 `Z` 布尔一致；完整组才算固定 `n` p 值，这个统计口径正确。但它不核验文件名 `job_{index}` 与 manifest 的预定 job 索引、代表 regime、初始三位置/对应 workload hash、每个 `outcome` 与 `failure/completed` 的一致性、或 `endpoint_time`/`policy_steps` 合法范围；任何同 SHA 的伪造/错置行可进入 `K`。例如将 `branches[-1].outcome` 改为 `energy_depletion` 并同步改 `Z`，其 `failure=None` 仍会被接受。最小修复：按 manifest 重建预期 `(index,group,seed)`，验证文件名与所有关键字段；枚举只允许四个 endpoint outcome，并由 `failure/completed` 及跳过规则重算标签；核对同组的三位置及 stream hash（可重建 workload 或记录独立输入摘要），完成后才给证书字段。原始物理真实性仍需受控运行来源/哈希，不可能只靠 JSON 证明。

**需修补 4：runner 恢复也只核旧行的 SHA 和 seed。** [`run_initial_choice_lb.py` 188–194](../../checks/run_initial_choice_lb.py)若某既有 row 的 SHA 与 seed 相同但容量、regime、分支次序或 `Z` 错误，会直接跳过；collector 虽能发现部分错误，却在整体运行结束后才报。建议恢复前复用 collector 的单行验证，失败即停止并保留原行，不静默覆盖。worker 分片本来按固定全局 job index 求模，改变 `--workers` 能重分配剩余行；manifest 未固定 worker count，状态文件不应被解释为全局完整性证据。`SIGTERM` 只在一个**完整初态三分支**后检查，进程中断可能重做当前初态；行级恢复是正确的，但不是航段中途恢复，首 checkpoint 的墙钟时长未被脚本界定。启动时应只验首个完整行健康并交还，不自动推进整批。

**collector 统计边界。** [`collect_initial_choice_lb.py` 69–89](../../checks/collect_initial_choice_lb.py)的二项上尾、Bonferroni 三组和「仅 complete 算 p 值」与 A02 一致。`rejects_all_policy_feasibility_at_5pct` 应解释为**该容量组原始模拟器中所有合法高层策略的耗尽风险严格高于 5% 的统计证据**，不是任何具体策略完成数、真实飞机安全或联合规划/学习性能结论。若要避免区间措辞与临界等号歧义，可用 `p_value≤α` 作为唯一预定拒绝规则，并令报告的下界描述为对应的闭区间边界；实际整数门槛在 `n=100,α=.05/3` 下无等号问题。

本轮未查新文献，也未使用论文论断；审查依据均为上述本地原始源码、冻结参数、历史协议和帖子。
