# 状态相关返站余量：首轮完整窗口探索实验

日期：2026-09-29。此目录是独立项目。`persistent_uav_throughput_v1/` 的冻结环境、导航器、模型和旧实验只读引用；现有 `persistent_uav_feasibility_20260929` 的 810 条筛查继续独立运行，不写入本实验目录。本轮依据用户授权启动新实验，但不训练网络、不改变低层物理或碰撞规则。

## 问题与最小对照

原问题：单 UAV、固定真实地图、Poisson 持续来单、初始 3 单/等待容量 5、非抢占单点服务、站内计时全充。完整原始窗口 `T=10905.05 s` 的效用是已完成任务数，风险是窗口内实际电量耗尽；目标阈值为 `δ=0.05`。本轮仅作探索，不作风险认证。

所有策略共用**同一合法基础规则**：空队列且站外可返站时立即 `recharge`；非空队列先筛选估计任务加返站成本满足余量的任务，并从中选预测服务时长最短者；无筛选通过任务且能 `recharge` 时返站；满电站内且无筛选通过任务时，按最小预测任务加返站成本执行合法 `serve`，记为 forced fallback。满电站内空队列由环境自动等待。此规则把 B5 的站外空队列等待风险修补公平给所有方法，但满电站内没有安全退路的问题仍在；不添加停机、拒单或非空队列 `idle`。

设 `Ehat_i` 是冻结模型预测当前位置至任务 `i` 的能耗，`Ehat_r` 是任务位置到站的预测能耗，筛选条件为 `battery > Ehat_i + Ehat_r + m(i)`。五个预先固定的方法只改变 `m`：

| 方法 | 两段总余量 `m(i)` |
|---|---:|
| U0 | 0 |
| U5 | 5 |
| U10 | 10 |
| U15 | 15 |
| C | 每段水平位移 `<2695.1064` 时加 4.1，否则加 6.5；任务和返站两段相加 |

`C` 的阈值取冻结的 1000 条校准航段水平距离上四分位；4.1 和 6.5 是已完成航段的描述性第 95 百分位约值，并已向上取整。**这些是在点估计器拟合同一批样本后的成功条件统计，绝不是实际能耗上界或风险保证。** 此分组只为检验“距离条件误差是否值得继续研究”。若短航段尾部或删失失败主导，C 可能无益。总余量 U5/U10/U15 给 C 的 8.2–13.0 范围提供强统一对照，U0 用来衡量共享规则修补的作用。

固定 `regime=(4,13,22)`：三档电池容量均取 `charge_tilde=1, eta=0.9` 的格，避免同时改变补能和负载。全新 seeds `1402609290..1402609299`，与旧校准、B4/B5、首任务检查和正在运行的 810 条筛查分离。共 `3×10×5=150` 个完整原始窗口，方法对同一 regime/seed 使用同一外生流。当前高层没有 LiDAR 字段，全部方法只用相同合法 `observe()`；没有未来流、真障碍图或反事实安全菜单。

## 判读与停止

每格报告 10 条完整运行的耗尽、导航失败、完成数、补能、队列溢出与统一碰撞计数；失败 run 的完成数照实计入。跨方法比较使用同流配对完成数，但同一流复用五次不增加风险独立样本。10 条即使零耗尽也不能认证 `δ=0.05`。三个 regime 是事前选定的机制探针，不代表全部 27 格。

先看 U0 与其他组的合法动作频率、forced fallback、任务/返站耗尽和完成数，判断余量有没有改变决策；再比较 C 与 U5/U10/U15 的风险及完成数。若 C 无稳定增益，停止条件余量路线或修改机制假设；若所有组主要被 forced fallback/导航 timeout 主导，不能把损失归因于余量；若 C 看起来更好，仍须在**新开发流**调优统一余量并于独立最终流验证完整窗风险，不能把本轮 10 条当论文结果。正确事件驱动 rollout 是后续单独消融，当前不实施或归功于 C。

本项目运行器原子保存每个完整 episode，写固定 manifest、原始事件与统一汇总；每个 worker 持有独占分片锁，收到停止信号后完成当前 episode 再退出。同版本同 manifest 可续跑。只做聚焦测试、一个短真实导航 smoke 和首 checkpoint 健康检查，随后交还运行，不监控至完成、不自动推广至 27 格/最终验证。
