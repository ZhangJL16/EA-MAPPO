# 二维双约束学习与强规划对照：实验计划

日期：2026-09-26。此计划属于独立项目 /home/zjl/uav_learning_research；不重开 /home/zjl/mappo 的结项课题。

## 问题锚点与可证伪主张

固定高度二维无人机持续完成一次一个目标，静态全图与合成能耗模型对策略和规划器均可用。每个执行步须保留避碰且电量足够的可执行返站续接。主指标为 600 仿真秒内完成目标数，碰撞、实际耗尽与返站失败单独报告。

- 主张 C1（待验证）：在同一信息、动作候选和联合安全过滤器下，学习策略在未见地图上的完成数高于强的有限视界 MPC。
- 支持性问题 C2（机制诊断）：避障控制改变返站轨迹成本时，行动过滤和充电决策是否产生可重复的相互作用；记录干预、续接裕量、返站与补能时间，不从零碰撞直接推断耦合。
- 必须排除的解释：比较对象只是补满电路线规则、RL 偷看未来目标、某方法获得特权真实地图/能耗、测试地图用于调参、学习收益来自更多计算或更松的安全约束。
- 若 C1 失败，保留负结果；用户允许随后单独进入多目标队列。不得把队列任务的结果写成静态单目标任务获胜。

## 公平接口与地图划分

训练图 ID 8–31（24 张），验证图 ID 32–39（8 张），冻结测试图 ID 40–55（16 张）；ID 0–7 只用于政策无关标定和历史诊断。所有方法在同一图中依次看到相同的候选目标流，不预看下一目标。学习与 MPC 都可看全静态地图、当前目标、站点、速度和电量；路线建议由同一可见图规划器产生。评价使用同一个真实物理步、耗能模型和联合过滤器。训练允许接触与耗尽，接触恢复和惩罚保持用户冻结协议；评价报告过滤前后的动作。

学习策略使用离散的局部航向偏移、速度和主动返站/充电动作；MPC 从相同可执行动作集中搜索，并用同一个路线与能量模型进行有限视界预测。MPC 运行时间单独计量；不能把它称作全局最优或无限视界 oracle。所有算法超参数只在训练/验证图上定一次，测试前冻结源码和配置哈希。

## 实验块

| 块 | 比较 | 主指标 | 决定性解释 |
|---|---|---|---|
| B1：静态全图主比较 | 路线＋补满、路线＋部分补能、有限视界 MPC、学习策略 | 成功完成数；碰撞/耗尽/返站失败；墙钟决策成本 | 学习必须与 MPC 比，而非仅胜过简单规则 |
| B2：安全耦合诊断 | 同一轨迹记录名义控制、CBF 调整、返站过滤、剩余续接成本 | 干预频率、返站次数、补能时间、动作反转样本 | 区分安全层的工作与策略自身的贡献 |
| B3：必要性/简化 | 学习策略有无路线提示或返站裕量特征；MPC 视界敏感性 | 配对完成数与安全率 | 防止学习模块或观测特征只是装饰 |
| B4：负结果后的新问题（条件分支） | 多目标队列下重新比较，预先保留单目标原结果 | 完成数、队列等待、任务选择及安全 | 仅当 B1 未支持学习收益且用户继续授权时作为新任务运行 |

主结论的充分证据：16 张冻结测试图上，以地图为配对单位、三个训练种子均有可复查结果；学习相对最强预冻结 MPC 的完成数差异为正，地图配对置信区间不跨零，且碰撞/耗尽/返站失败不增加。若不满足，报告数值、区间和失败原因，不改成功门槛或测试图。安全零事件只报告经验样本，不宣称总体风险保证。

## 一次性代码冻结后的运行顺序

1. 实现原始训练环境、统一动作/观测适配、强 MPC、学习训练、评测与可恢复矩阵调度；保持历史 map 0 结果不变。
2. 对新路径做针对性测试、一次很小的执行 smoke 和首检查点恢复健康核查。此处只检查运行有效性，不根据方法差距调场景。
3. 冻结配置与哈希后，启动一份可恢复的长任务矩阵：三种学习种子，各至少 50,000 个训练决策；验证图选择固定配置；冻结测试图上完成 B1–B3。最终训练步数和计算预算在正式启动前由实测小 smoke 墙钟成本写入 manifest，不按 test 成绩增减。
4. 自动汇总配对差异、地图级 bootstrap 区间、失败事件、过滤器干预及决策时间。原始轨迹和检查点保留；报告清楚区分模拟证据与真实飞行。

预计计算瓶颈是每个高层决策都运行返站轨迹，现有 map 0 基线 600 仿真秒约耗 144 墙钟秒。MPC 候选搜索会更慢；须记录实际候选数和求解墙钟时间，避免隐藏规划计算。24 逻辑 CPU、23 GiB 内存、8 GiB GPU 可用；小网络训练主要受模拟器而非 GPU 限制。此处不以粗略估时承诺完成日期。

## 后续扰动阶段的边界

若转向能耗误差或动态障碍，返站过滤器只能基于已观测数据与明确假设构造保守能量上界；实际耗尽和碰撞如实报告。确定性静态阶段结果必须先独立封存。动态障碍可能永久阻断道路，因此不能无条件宣称始终可返站。
