# 安全导航重新设计：从头训练，不再锁定 R3

日期：2026-09-05。当前状态：**方向保留编码器与普通 PPO 学习性试跑已实现、启动；PPO-Lagrangian/FOCOPS 与能耗训练尚未启动**。

执行进展见 [方向编码与 PPO 试跑记录](DIRECTIONAL_PPO_PILOT.md)。下文文献与资产审查中的“尚未实现”描述保留当时阶段语义；当前执行状态以此处和对应运行目录的 `status.json` 为准。

## 1. 决定与理由

2026-09-05 资产复用审查进一步修订：**原结构化 LiDAR 的全局 mean/max 读出会消除绝对水平角，不能原样复用整个提取器。** 已在冻结 R3 和真实射线几何四方位诊断中确认：原始观测不同、最终编码相同。保留双通道、环绕卷积和完整射线，先验证有序空间读出，再比较安全算法。见 [复用审查与可复现诊断](SAFE_NAVIGATION_ASSET_REUSE_AUDIT.md)。该发现不是已证明的唯一失败原因；生产代码与旧权重尚未更改。

2026-09-05 后续引用审查修订：下一条主线是 **标准 PPO-Lagrangian 与 FOCOPS 的有限任务候选对照，从随机初始化训练，不预定赢家**；普通 PPO 只作基础学习能力参照。仅比较 FOCOPS 和普通 PPO，不能隔离成本约束与策略更新规则的作用。R3 只作为冻结经验模型，不蒸馏、不行为克隆、不强制继承权重。保留有效的物理仿真加速和完整 LiDAR 数据，不将“换方法”误解为重写仿真或减少输入。

这是可检验的工程选择，不是“已经证明最适合”的结论。选择依据是：当前失败需要首先分离导航收益、安全成本和策略更新；FOCOPS 有可核验的一阶算法与作者代码，不依赖在线 MPC 或额外世界模型。调研见 [14 篇文献及实现核查](../literature-search-20260905-safe-rl-from-scratch/papers.md)。

新增[后续引用批判审查](../literature-search-20260905-safe-rl-forward-citations/papers.md)：FOCOPS 在后续导航论文中结果混合；SafeMPO 原文 B=25 的三个导航任务均值成本均超过25，故降为理论参考而非优先升级方案。SAC-Lagrangian 仍是有场景近邻证据的备选，不能因 off-policy 身份直接排除。上述修订仅更新研究判断，尚未实现或运行。

不再继续给上一轮 reach-avoid SAC 分支加补丁。为了避免增加一个成本价值函数而替换原 SAC 奖励、Bellman 目标和熵语义，实际上是更大的算法改动；此前应更早把这个风险放在首位。精确 Bellman 算子收缩不保证深度 actor-critic 学习稳定。

## 2. 已确认的失败证据

原始证据：`artifacts/r3_reach_avoid_pair_50k_each_20260905_v1/RESULT.json`。每个模型均为相同 50 个开发任务，不能当作独立训练种子的统计复现。

| 模型 | Shield-on 安全到达 / 碰撞 / 超时 | Shield-off 安全到达 / 碰撞 / 超时 |
|---|---|---|
| 冻结 R3 | 47 / 0 / 3 | 26 / 24 / 0 |
| hard 50k | 7 / 0 / 43 | 2 / 28 / 20 |
| continuous 50k | 1 / 1 / 48 | 1 / 35 / 14 |

结论：两条新分支均损害导航，且未显示自主避碰改善；不是“多训练一些就会好”的证据。R3 的 shield-on 47/50 也不能表述为网络自己有 94% 的安全到达能力。

另做只读价值范围审计：固定 hard 10k replay 中随机种子 930001 抽取的 1,024 个状态，对十个保存的模型计算 `min(Q1,Q2)(obs, actor(obs)) + phi`。该量的精确目标属于 [0,1]。

| Checkpoint | hard 平均值 | hard 范围越界比例 | continuous 平均值 | continuous 范围越界比例 |
|---|---:|---:|---:|---:|
| 10k | 0.7067 | 0.39% | 0.6925 | 0.20% |
| 20k | 0.7308 | 2.25% | 0.7535 | 3.42% |
| 30k | 0.7933 | 9.08% | 0.8032 | 12.60% |
| 40k | 0.9007 | 25.49% | 0.8945 | 29.79% |
| 50k | 0.9537 | 38.77% | 0.9650 | 45.31% |

50k 最大值分别 1.4521 / 1.3905。与此同时，使用同批 replay 动作的均值也达到 0.9507 / 0.9620，说明问题不只是在新 actor 动作上的局部乐观。此处是**价值函数越过理论取值范围**，不是飞行器位置越界。

能确认：价值估计失真、两组行为退化、仅靠有限 TD loss 无法验证训练有效。不能确认：价值失真是唯一原因，或者具体某一行代码造成了全部失败。该固定旧状态审计不是概率校准，也没有独立识别因果。

仍需区分的因素：

1. 离策略自举和策略更新相互放大误差：目前有范围失真的直接证据。
2. 用折扣到达值取代原导航回报，导致实际信用分配和优化尺度变化：确定发生，但尚未隔离贡献。
3. 10k MC 初始化只使用完成轨迹，存在完成选择偏差；长超时轨迹没有完整标签。
4. Shield 改变执行动作，掩盖自主能力；单帧局部观测也不自动满足完整 Markov 假设。这两点均不能靠换优化器自动解决。

## 3. 为什么不是“之前 PPO 已失败，再重复一次”

已核对 `experiments/r7_cppo_pid/algorithm.py` 与 `scripts/train_r7_cppo_pid_navigation.py`。旧 R7：

- 成本是动作修正平方量加物理接触惩罚；默认预算 300，不是整趟任务碰撞概率。
- 使用 PID multiplier、独立标准化的 reward/cost advantages，并始终开启 HOCBF。
- 对 terminated/truncated 的统一处理是否正确，取决于它代表真正任务期限还是采样截断；不能脱离任务定义一律判 bug。

所以本次改变是**成本对象和训练合同**，并分别核对标准 PPO-Lagrangian 与 FOCOPS 的更新目标，而不是给旧 CPPO 改名。新发现的读出问题是两种候选共同需要先处理的表示限制。

## 4. 冻结最小问题定义

一次导航任务在首次真实接触、无接触到达或任务期限 H 时结束。接触由原物理模拟的 obstacle_collision / boundary_contact 给出，四个物理子步内任一次接触都必须保留。接触和到达同一步时，接触优先。

保留底层“碰撞/边界后移到合法位置并速度归零”的修复行为；在训练 wrapper 中将首次接触标记为本次任务失败并结束。不能把修复后抵达目标计为无碰撞成功，也不能把修复位移算成有效导航进展。这个逻辑终止合同与历史持续修复任务不同，因此必须对所有新对照一致应用，不能直接拿旧总回报跨合同比较。

定义 c_t = 当前转移首次发生物理接触的指示量。因为任务首次接触即结束：

`sum_t c_t = 1{本次任务发生接触}`，因此 `J_C(pi)=E[sum_t c_t]=P(接触)`。

目标是最大化任务回报 `J_R(pi)=E[sum_t r_nav,t]`，约束 `J_C(pi)<=delta`。这里 r_nav 保留原来进展、到达、时间等导航反馈的意义，不替换成“存活值”；奖励系数与终止奖励要在实现合同中逐项列出。有限期限使两个总和均有限。首版采用不折扣的有限任务定义，不能偷偷沿用 gamma_c=.99 再声称是概率约束。

delta 是任务允许风险的工程参数，不是定理推导出的达标线。可使用 0.05 作为**探索运行配置**观察约束能否学到，但不能把它当作用户确认的部署安全要求；最终标准仍需确定。报告完整风险—到达率变化，不因任意阈值未达就否定研究价值。

仅限制碰撞会允许悬停到超时；因此到达率、超时率和进度必须独立报告。低接触率而不执行任务不算成功。

## 5. 最小网络和优化

- 一个随机初始化的连续动作 actor。
- 一个导航状态价值 V_R，以及一个碰撞成本状态价值 V_C。不是三个 critic，也不是在 SAC 两个 Q 上继续堆多个安全网络。
- 第一版复用 LiDAR 双通道和局部卷积，不原样保留已确认丢失方位的全局池化；有序 2×16 读出作为待实现候选，须记录增加的参数与耗时。不借用 R3 权重，不降低原始 128×8 雷达分辨率；两组使用相同结构。特征压缩不是原始雷达降采样，但也不能宣称全部几何信息无损。
- 明确加入剩余任务时间供有限期限价值估计使用。它不是几何语义模块或创新点；单帧雷达仍有部分可观测性，不能由加时间宣称已经完全 Markov。
- 第一版不加入 RNN、世界模型、模仿损失、能耗头、恢复策略或安全课程。若以后需要，必须由单独诊断支持。

FOCOPS 的核心是使用当前策略数据，形成导航优势与成本优势，再做 KL 控制的策略更新。保持作者的一阶投影式目标；不用 PPO clip loss 冒充 FOCOPS。采样概率、KL 均在策略输出的随机变量空间计算：若后续经过 tanh、径向限幅或物理缩放，应存储相应 latent action / old log probability；不能拿修正后的动作代替采样动作计算 PPO/FOCOPS 比率。

本项目有限期限、首次接触成本、不折扣累计回报是**明确的应用适配**。原 FOCOPS 的无限期折扣误差界不能直接代入 gamma=1。成本事件恒等式和有限期 Bellman 递推见 DERIVATION_PACKAGE.md 的 FH-CMDP 节；神经网络/GAE/采样 KL 约束仍为近似。

优势尺度要可追踪：首版不独立白化 reward 与 cost 后仍将 multiplier 称作原始成本单位。若需要归一化，必须记录比例并将其反映到 multiplier/目标中；同一正比例缩放合成优势不改变 reward-cost 相对权重，但会改变它相对 KL 项的尺度，也须记录。

## 6. 数据收集与终止：先解决，不能边训练边猜

1. 有限任务期限、到达和接触属于真正终止，价值 continuation 为零。
2. 仅为采样/保存截断的 rollout 要从对应 terminal observation bootstrap；不得使用自动 reset 后的新观测。
3. multiplier 所需的整任务成本不得用“本批恰好完成的短轨迹”冒充无偏统计。第一版 correctness reference：固定当前策略，收集预定数量完整任务，再更新；允许向量化异步执行，但完成的槽位不能偷偷向同一队列补入无限短任务。每任务等权。
4. 若完整长任务使 reference 太慢，必须显式改为可审计的截断/价值估计方案，标记其偏差；不能为了时长直接用短轨迹均值替代。
5. 变长任务的优势与 KL 统计要记录轨迹权重；finite-H 吸收填充或等价权重可用于统一占用分布。按 transition 和按 episode 的平均不是同一对象。
6. 存储模型、两个价值估计器、优化器、随机状态、全局步数、任务合同版本及未完成采样状态。若续跑不能恢复模拟器，明确是重启未完成任务，而非逐位继续。

## 7. 下一步实验，不是现在立即挂长跑

先实现隔离的新目录和单元测试，不改已有 R3/R7/失败分支。测试：早晚接触同成本、子步接触不丢失、接触优先于到达、修复后仍判失败、任务期限与采样截断区别、auto-reset observation、Gaussian logprob/ratio、KL 方向、multiplier 更新符号、不同任务长度下成本统计、断点续跑。

随后做一个小型可解 CMDP 单元例和真实仿真 smoke，并测量环境采样、GPU 更新、完整任务采集各自耗时。有限 loss 只说明执行通过；还应确认成本确实推动动作分布远离风险，KL 控制生效，并排查导航进展是否退化。

首轮先检查普通 PPO 的导航学习性，再顺序比较标准 PPO-Lagrangian 与 FOCOPS：相同任务、容量、真实接触成本与预算，记录等环境 transition 及实际墙钟结果。不是同一网络叠加算法，也不同时启动所有候选。预算根据真实 throughput 选择，首轮目标数小时且不超过用户历史 10h 范围；不加不可续跑的硬 kill。完整任务采集可能使最后一批稍超过 transition 目标，须记实际步数。不要照搬上次 50k 预算来判定从头学习不可行。

学习主评估采用 **shield-off 仿真**，这样结果直接对应网络能力。物理限幅和原碰撞修复保留；这不是允许真实无人机不受保护探索。Shield-on 只作独立辅助评估，不混入训练成功率。

开发集固定且与训练任务分离，报告无碰撞到达/接触/超时三个互斥结果、成功路径比、训练交互和 wall time。路径比须同时标成功样本数，不能比较 1 次成功和 47 次成功的平均值就宣布路径变好。

若普通 PPO 也没有导航进展，先审计探索/奖励/观测与学习实现；不能归咎于安全约束。若 PPO 可达而 FOCOPS 停滞，再隔离成本估计、预算和更新尺度。只有这两层证据清楚后，才考虑 SafeMPO、课程或表征模块中的一个。500 次正式测试留给通过开发验证的冻结模型，不用反复在正式集调参。

## 8. 安全与能耗的关系

当前工作只建立可靠的碰撞安全导航平台，尚不是能量可持续导航的最终实验。未来能量安全可视为剩余资源与返航可达性约束，但不能先把碰撞安全训练和新的能耗方法叠在一起再解释失败。

采用成熟 FOCOPS 不作为原创贡献；有限期事件成本恒等式也不是新定理。论文创新仍需在可验证的能量安全问题上建立，不能由采用一篇顶会算法推导“达到 oral 水平”。
