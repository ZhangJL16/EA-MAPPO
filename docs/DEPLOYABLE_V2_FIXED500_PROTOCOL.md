## 指标与分析顺序

主要指标：到达率、零碰撞到达率，均分距离档报告。次要指标：超时、统一
碰撞次数的均值/中位数/尾部，以及路径比与实现能耗。不能只报告最优checkpoint；
本轮预先固定最终checkpoint。不将更少能耗但更多超时解释为节能优势。
方法间路径与能耗对照应另报共同到达任务，避免成功子集变化造成选择偏差。

评测完成后检查：
1. 新旧结果是否在同场景下确有碰撞恶化，是否集中于长距离或少数反复接触。
2. 完整配对统计和场景条件的不确定性；跨种子结论仍保留。
3. 若出现可信退化，下一次只隔离一个因素：例如在编码器内从现有距离重建
   命中通道，保持部署仍只接收1024距离，而不是立即堆新的安全模块。
   阈值特征无独立传感信息，但可能改变学习难度；这是待检验假设。
4. 若导航维持可用，转到显式资源决策目标，而不是因为加了电量就宣称节能。
   未经本轮结果判断，不自动触发以上分支。

## 为什么仅增加电量不等于学到能源安全

本轮目标仍为最大化导航期望奖励。完整物理状态给定时，若奖励、可用动作、
动力学与终止条件均不随预算改变，仅扩展状态为(x,b)不要求最优策略对b作
节能响应。这里的b可能作为部分可观测历史代理影响学习，但这不是能源安全
目标的替代品；return_command在训练中恒0也无法提供返航模式覆盖。

后续资源任务至少要明确：什么任务收益需要保留、预算如何约束执行、在哪里
视为充电成功、未安全返航如何计入风险，以及策略到底能选择哪些任务/返航
动作。可研究事件

    P(到达充电站且累计能量≤b且统一碰撞次数=0 | 可用观测历史, 执行策略)

但碰撞只让这一评分事件失败，不终止物理导航；不得改动用户锁定环境。
这是下一阶段问题定义，不在当前500导航评测中伪造能源安全标签或保证。
