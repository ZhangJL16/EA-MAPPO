# 平台 Gate 与部署 Gate 拆分协议

日期：2026-09-06。状态：**已由用户确认采纳**（2026-09-06 三选一决策）。

## 1. 决策记录（用户拍板，锁定）

1. **投稿日历**：跳过 ICLR 2027（abstract 2026-09-18 / 全文 2026-09-25 已无法承载完整证据链），执行三个月计划，主攻 **ICML 2027 / RSS 2027**（预计 2027 年 1–2 月截稿）。
2. **Gate 拆分**：导航验收拆为两层——**平台 gate**（放行下游能源/返航研究）与**部署 gate**（工程质量目标，不再阻塞研究）。
3. **导航止损线**：若 2 周内 reward-only PPO 在开发集 50 任务上 shield-off 到达率 < 60%，即冻结"R3 + HOCBF"为论文平台（shield-on 47/50 已够用），停止导航再训练，全部资源转回返航决策主线。

## 2. 平台 Gate（下游实验放行条件）

适用对象：论文的导航平台（冻结策略 + HOCBF shield）。评估：500 任务固定集合（seed 不变）+ 50 个未见场景（新 seed，新增项）。

| 指标 | 要求 | 理由 |
|---|---|---|
| shield-on 无碰撞到达率 | ≥ 0.85（CI 下限 ≥ 0.80） | 支撑电池标定/返航决策实验的任务样本量；文献中未见/杂波静态环境学习导航典型 60–88%，0.85 处于"平台可用"而非"部署质量"区间 |
| 距离分桶最低桶 | ≥ 0.70 | 保证各任务距离段均有样本 |
| 障碍碰撞步 | = 0（shield-on） | HOCBF 几何保证下的平台安全验收，JSEB 500k 已证明可达 |
| 边界接触步率 | < 0.01 | 沿用原定义 |
| 平均路径比 | ≤ 1.5 | 平台效率下限；论文不主张路径最优 |

通过后授权：Stage 1（冻结平台）→ Stage 2-3（电池标定/验证）→ Stage 4（Oracle headroom）→ Stage 5-7（ETG 学习、组合偏移、可靠性、返回 Pareto）。导航 success/路径比/碰撞仍为强制报告列与敏感性分层变量。

## 3. 部署 Gate（工程目标，不再阻塞）

维持历史阈值：overall ≥ 0.98、分桶 ≥ 0.95、路径比 ≤ 1.10、碰撞步 = 0、边界接触 < 1%。用途：论文 limitations 中的工程目标陈述与未来部署验收；**不构成任何下游实验的前提条件**。历史 R0–R5 的失败记录保留为描述性证据（其中 R5 已达 0.938/1.098，距 gate 一步之遥）。

## 4. 平台决策规则（止损）

- 优先路线：方向保留编码器 + reward-only PPO（用户冻结的碰撞语义下），2 周预算。
- 止损条件：开发集 50 任务 shield-off 到达率 < 60% → 终止导航再训练，冻结"R3 加速复现 500k + HOCBF"为论文平台（shield-on 47/50），并发起 500 任务平台 gate 评估（按 §2 标准）。
- 若平台 gate 评估 FAIL（< 0.85）：先诊断再决定，不得无限重训；允许用"平台 gate 通过的任一冻结模型"（含几何启发式 + HOCBF，历史 smoke 9/10 到达、零碰撞、路径比 0.996）作为备选平台。
