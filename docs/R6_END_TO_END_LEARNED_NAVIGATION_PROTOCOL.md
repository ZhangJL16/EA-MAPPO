# R6 End-to-End Learned Navigation Protocol

## Scope

R6 repairs the navigation substrate without changing or relabeling the frozen
R3 return-to-charge evidence. It asks whether the neural policy itself can learn
goal-directed collision avoidance with low safety-filter dependence. It does not
introduce global planning, waypoints, PD control, or heuristic deadlock branches.

## Model

For observation \(o_t\), executed-loop feedback \(f_{t-1}\), and recurrent state
\(z_{t-1}\), the policy is

\[
z_t=\operatorname{GRU}_\theta(\operatorname{Attn}_\theta(o_t),f_{t-1},z_{t-1}),
\qquad a_t^{\rm nom}\sim\pi_\theta(\cdot\mid z_t).
\]

Each LiDAR ray is represented by normalized range, hit validity, and its fixed
three-dimensional direction. A goal-conditioned query attends over ray tokens.
The feedback vector contains the previous executed action, continuous HOCBF
intervention norm, and physically normalized progress. It contains no expert
route or hand-crafted navigation action.

## Executed-Loop Semantics

The environment applies its unchanged safety operator

\[
a_t^{\rm exec}=\mathcal S(x_t,a_t^{\rm nom}).
\]

PPO log likelihood is attached to \(a_t^{\rm nom}\), the action actually sampled
from the policy. State transitions are generated by \(a_t^{\rm exec}\). The
safety teacher enters learning through

\[
L_{\rm distill}=
\frac{\sum_t\|a_t^{\rm exec}-\mathbb E_\pi[a_t]\|_2^2
                 \|a_t^{\rm exec}-a_t^{\rm nom}\|_2}
     {\sum_t\|a_t^{\rm exec}-a_t^{\rm nom}\|_2+\varepsilon}.
\]

This is continuous weighting, not an intervention threshold or switching rule.

## Constrained Objective

R6 maximizes navigation return subject to collision and intervention costs:

\[
\max_\theta J_r(\theta),\quad
J_c(\theta)\le 0,\quad J_I(\theta)\le 0.
\]

Nonnegative multipliers are learned by projected dual ascent. PPO uses the
combined advantage \(A_r-\lambda_cA_c-\lambda_IA_I\), while separate value heads
estimate reward, collision cost, and intervention cost. Progress and task
completion remain the objective reward; safety costs are not hidden inside a
manually weighted reward.

Each value head uses a Huber regression objective. This preserves quadratic
local fitting while preventing the first sparse task-completion bonuses from
dominating the shared representation through very large squared residuals.

## Evidence Contract

- R3 files and checkpoints are not overwritten.
- Every R6 run uses a fresh artifact directory and records source hashes,
  command, device, transition accounting, losses, gradient norms, KL, collision,
  intervention, and completed-episode metrics.
- A smoke run is non-scientific. It only validates finite losses/gradients,
  nominal/executed action semantics, checkpointing, and CUDA execution.
- The longer development run has an external wall-clock timeout below ten hours.
- High success with sustained high HOCBF intervention is not accepted as learned
  navigation; intervention and emergency-brake rates remain first-class results.
- Navigation success thresholds from the old R3 engineering protocol remain
  descriptive comparators, not theorem assumptions and not retroactive labels.
