# EIRR and Return-to-Charge Claim--Evidence Matrix

## Mode and invariant

Mode: standard experiment-evidence design.  The invariant outcome remains the
stranding--throughput Pareto frontier of the irreversible return decision.
Prediction and risk-resolvent quantities are mechanism evidence, not substitutes
for that outcome.

No result is invented below. `TBD` means that the named formal Gate or experiment
has not produced admissible evidence.

## Current Gate verdict

The active conditional branch uses the user-selected frozen R3/HOCBF platform.
R3's historical deployment-quality navigation verdict remains FAIL, but its
success, path, and collision metrics are descriptive strata rather than theorem
assumptions. A hash-bound fixed-platform contract and a recomputed 500-task
battery-calibration attestation are complete. The first 100-run endurance audit
was invalid for the intended estimand because 41 runs ended at the task-step
limit rather than true depletion. That artifact is retained as right-censoring
evidence. A version-2 audit is now running in ten-run atomic batches under a
continuous-workload estimand: failed tasks roll over without resetting physical
state, time, distance, or battery, and every admissible run must end in true
energy exhaustion. Oracle Headroom remains non-evaluable until that audit
produces a complete passing artifact. TD readiness and learned methods remain
gated behind Oracle Headroom.
