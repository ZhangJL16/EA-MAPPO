# Coupled Safety Operator

## Target

Define the energy-return object generated by a collision-filtered charger policy and determine when a collision-independent energy critic is structurally misspecified.

## Status

COHERENT AFTER PROBLEM REFORMULATION.

## Invariant Object

The invariant is the versioned, budget-conditioned defective law

`F_E^eta(. | x,a,d,b) = Law(Z_tilde_E^eta(x,a,d,b))`,

not two independent critic outputs.

## Charger Kernel Induced by Collision Learning

For remaining budget `b`, define

`D_eta(x,b) = {(a,d): a in supp pi_theta(.|x,g_c), U_C,eta^1(x,a)<=d<=b}`.

Given a declared allocation kernel `K_eta(d|x,a,b)`, the charger deployment kernel is

`kappa_{C,eta}(a,d|x,b)`

proportional to

`pi_theta(a|x,g_c) K_eta(d|x,a,b) 1{(a,d) in D_eta(x,b)}`,

when the normalizer is positive. Empty support is an explicit failure state. Other deterministic selectors are allowed, but their rule is part of `eta`.

This is the shared charger-goal policy after collision-based action restriction. It is not an independent return or recovery controller.

## Defective Return Law

Starting from `(x,a,d,b)`, execute `(a,d)` once. Thereafter sample from `kappa_{C,eta}` with residual budget. Set

`Z_tilde_E^eta = sum_{t<T_c} c_t`

if `T_c < min(T_B,T_empty)` and set `Z_tilde_E^eta=+infinity` otherwise. Then

`F_E^eta(z|x,a,d,b)=P(Z_tilde_E^eta<=z)`

has finite mass

`F_E^eta(+infinity-) = P(T_c < min(T_B,T_empty))`.

The missing mass cannot be removed from the data table and then called a return-energy distribution. A conditional finite-return distribution may be reported only together with this success mass.

## Proposition C1 — Budget Is a Necessary Predictor in General

**Claim.** There exists a finite charger SSP and a fixed collision-filtered base policy for which two residual budgets `b_L<b_H` induce different charger-return laws at the same physical state and first action. Consequently, no budget-agnostic law `F_hat(.|x,a)` can represent both exactly.

**Construction.** A common zero-cost first action reaches state `y`. At `y` there are two charger actions:

- detour: collision probability `0`, energy `10`;
- shortcut: collision probability `epsilon in (0,1)`, energy `1` on success.

The base policy ranks shortcut first and the filter selects the highest-ranked admissible action. Let `b_L<epsilon<=b_H`. The low-budget kernel selects detour, so its defective CDF is `F_L(z)=1{z>=10}`. The high-budget kernel selects shortcut, so `F_H(z)=(1-epsilon)1{z>=1}` for finite `z`, with missing mass `epsilon`.

At `z=5`, `F_L(5)=0` and `F_H(5)=1-epsilon`. For every single budget-agnostic estimate `F_hat`,

`max(|F_hat(5)-F_L(5)|, |F_hat(5)-F_H(5)|) >= (1-epsilon)/2`.

Thus the residual risk budget and filter version are not optional metadata when they alter future action support.

## Proposition C2 — Admission-Boundary Discontinuity

In the construction above, changing the shortcut bound from `epsilon-rho` to `epsilon+rho` around fixed budget `epsilon` changes the continuation law from the shortcut law to the detour law for arbitrarily small `rho>0`. Therefore arbitrarily small collision-bound updates can induce order-one changes in the energy target when an action lies on an admission boundary.

This refutes any training protocol that updates `U_C` while treating `Z_E` as a stationary target without versioning or recollection.

## Proposition C3 — Margin Stability

Fix a finite candidate set and deterministic allocations. Suppose every candidate has admission margin at least `r>0`:

`|U_C,eta^1(x,a)-d(x,a,b)| >= r`

on every augmented state visited before absorption. If a new bound satisfies

`sup_{x,a}|U_C,eta'^1(x,a)-U_C,eta^1(x,a)| < r`

and base policy, allocator, tie-breaking, dynamics, and energy law are unchanged, then the admissible support and induced kernel are unchanged on those states. Hence the path law and `F_E` are unchanged there.

**Proof.** The strict perturbation cannot change the sign of any admission inequality. The candidate support is therefore identical. All other kernel components and the environment law are fixed, so induction over path prefixes gives identical path measures and identical return laws.

This is a target-stability condition, not a neural-network convergence theorem. It is deliberately strong and empirically testable through admission margins.

## Novelty Boundary

Augmenting an MDP with a budget is known. The potentially differentiating object is narrower: a calibrated local hazard changes the support of the same goal-conditioned policy, which endogenously changes a defective distributional SSP target and creates measurable target discontinuities. If closest work already learns and calibrates this exact versioned operator, the route is blocked.
