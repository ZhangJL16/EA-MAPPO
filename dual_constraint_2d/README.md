# 二维双约束研究模块

**状态（2026-09-26）：合成环境的标定和最小任务循环已实现；尚未训练策略或运行正式方法比较。** 该模块位于独立项目 `/home/zjl/uav_learning_research`。此前三维解析导航和 M100/1 km 配送方案保留作后续验证，不因本轮二维诊断改写。

首版是 200 m × 200 m 的固定高度二维场景，每图 8 个圆障碍、1 个站点；每次只有一个目标，完成后再抽下一个。飞行物理步为 0.05 s，策略决策间隔为 0.5 s；运营窗口为 600 **仿真秒**。策略和执行过滤器都读取完整静态地图，因此不能称为局部 LiDAR 部署。合成能耗为 `Δt·(c₀+cᵥ‖v‖²+cₐ‖a‖²)`，不代表 M100 实测功率。

[`synthetic.py`](synthetic.py)、[`routes.py`](routes.py)与[`reference.py`](reference.py)实现地图、路由和政策无关参考航段。[`calibration.py`](calibration.py)的 8 图 × 8 候选任务已经 **64/64 完成**，按预定规则冻结容量 85.3912 合成能量单位、完整充电时间 29.9 仿真秒。原始结果、manifest 和 SHA 见[标定与集成报告](CALIBRATION_AND_INTEGRATION_20260926.md)。[`targets.py`](targets.py)用参考可执行往返与满电预算筛选目标；当前 64 个候选中有 58 个通过。

[`backup.py`](backup.py)从完整飞行状态执行一条避障返站备用轨迹。[`shield.py`](shield.py)在执行策略的 0.5 s 动作前，检查整个动作块以及块末返站轨迹；执行中逐 0.05 s 复核状态和剩余预算。被拒绝时，系统执行已核验的返站轨迹。这里的“核验”只在确定性模拟器、固定地图、控制器和合成能耗模型下成立，**不是连续时间或真实无人机的形式化安全证明**。备用控制器失败也不意味着不存在其他安全路线。

[`environment.py`](environment.py)提供连续单目标任务状态机：站内 idle 零耗能、不自动充电；充到指定比例按事件推进仿真时间；返站时当前目标保留，补电后继续；送达后才出现下一目标。该接口还不是 Gym 训练环境。训练期允许试错并记录失败、评价期使用双过滤层的双通道尚未实现，不能称为 RL 已可训练。已有[公开接口 smoke 证据](../artifacts/dual_constraint_2d_integration_20260926/environment_smoke.json)：1 次送达、1 次回站、1 次部分充电并重新出发，零接触。它只验证流程连通性。
